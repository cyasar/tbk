Ders İçeriği · Tarayıcının Dili: Modern JavaScript ve ES6+

HTML iskeleti, CSS görsel tasarımı oluştururken JavaScript web sayfalarına yaşam ve dinamik davranış kazandırır. Tarayıcıların içinde yerel olarak çalışan, olay güdümlü (event-driven) ve yüksek seviyeli bir programlama dilidir.

Modern ECMAScript (ES6+) standartlarıyla birlikte eski var yerini blok kapsamlı let ve sabit değerli const anahtarlarına bırakmıştır. Temel veri tipleri: Number, String, Boolean, Array (dizi) ve Object (nesne) yapılarıdır.

Şablon dizgileri (Template Literals: `Sıcaklık: ${temp} °C`) string birleştirmeyi basitleştirirken; ok fonksiyonları (const carp = (a, b) => a * b;) daha temiz ve modern bir sözdizimi sunar.

DOM Ağacı ve Dinamik Sayfa Güncelleme

Tarayıcı bir HTML belgesini yüklediğinde onu Document Object Model (DOM) adı verilen hiyerarşik bir nesne ağacına dönüştürür. JavaScript bu ağaçtaki her düğüme erişebilir ve değiştirebilir.

document.querySelector('#sensor-value') seçicisi ile istenen HTML elemanı yakalanır. Elemanın metni textContent, HTML yapısı innerHTML ile güncellenir.

Görsel durum değişikliklerinde doğrudan inline stil yazmak yerine classList.add(), classList.remove() veya classList.toggle('active') metotları kullanılarak CSS sınıfları tetiklenir.

Olaylar (Events) ve Kullanıcı Etkileşimi

Web sayfaları reaktiftir; kullanıcının veya sistemin ürettiği olaylara yanıt verir.

addEventListener('click', () => { ... }) metodu en temel etkileşim köprüsüdür. Kullanıcı bir butona bastığında, form doldurduğunda (input), seçenek seçtiğinde (change) veya sayfayı kaydırdığında JavaScript fonksiyonları çalışır.

Elektrik-elektronik projelerinde bir web butonuyla röle açıp kapatmak, butona basıldığı anda aria-pressed durumunu değiştirmek ve ekrandaki LED göstergesini yeşilden kırmızıya çevirmek olay dinleyicileriyle gerçekleştirilir.

Asenkron Programlama, JSON ve Fetch API

Gömülü bir cihazdan (ESP32) veya buluttan sensör verisi gelirken tarayıcının donmasını önlemek için asenkron (non-blocking) programlama kullanılır.

JSON (JavaScript Object Notation), sensör telemetrisini ve yapılandırılmış veriyi taşımak için küresel standarttır ({ "sensor": "DHT11", "temp": 23.5 }).

Fetch API (fetch()) ve async / await sözdizimi ile tarayıcı sayfayı yenilemeden arka planda sunucudan veri çeker. Alınan JSON verisi doğrudan DOM'a basılarak canlı izleme sağlanır.

Elektrik-Elektronik Uygulaması: Canlı Telemetri ve Güç Hesabı

JavaScript mühendislik laboratuvarında doğrudan hesaplama ve gösterge aracı olarak çalışır.

Kullanıcının formdan girdiği gerilim (V) ve akım (A) değerlerini input olayıyla anlık okuyarak P = V * I formülüyle elektriksel gücü hesaplar ve ekrandaki <output> elemanına yazar.

Sensör simülatörü ile Math.random() kullanılarak belirlenen aralıkta (ör. 20–30 °C) test verileri üretilir ve periyodik olarak (setInterval) ekrandaki göstergeler canlı tutulur.

Hata Ayıklama ve Geliştirici Araçları: DevTools, GitHub Pages & Antigravity

Tarayıcı Geliştirici Araçları (DevTools) Console sekmesi, console.log() ve console.error() çıktılarıyla JavaScript kodunu adım adım takip etmeyi sağlar. Sources sekmesinde Breakpoint konularak değişkenlerin çalışma anındaki değerleri incelenir.

GitHub Pages üzerinde çalışan projelerde istemci taraflı tüm JavaScript mantığı sorunsuz çalışır (sunucusuz SPA mimarisi).

Google DeepMind Antigravity ortamı, karmaşık JavaScript fonksiyonlarında asenkron hata yakalama (try...catch), DOM bellek sızıntılarını önleme ve güvenli kod üretimi konularında mühendise akıllı ajan desteği sunar.

Gerçek Dünya Örneği

Laboratuvardaki bir akıllı ev otomasyon paneli için hazırlanan JavaScript kodu; kullanıcı 'LED Yak' butonuna bastığında ekrandaki sanal göstergeyi aydınlatır, ESP32 web sunucusuna asenkron HTTP isteği yollar ve gelen sıcaklık ölçümünü sayfayı hiç yenilemeden 2 saniyede bir günceller.

Uygulama

  • querySelector ve addEventListener kullanarak bir butona tıklandığında ekrandaki sensör değerini güncelleyen fonksiyon yazın.
  • LED durumunu açık/kapalı olarak değiştiren, CSS sınıfını tetikleyen ve aria-pressed değerini güncelleyen bir etkileşim kurun.
  • Gerilim (V) ve akım (A) girdilerinden anlık güç (W) hesaplayan reaktif bir form geliştirin.
  • Antigravity AI asistanı ile JavaScript kodunuzda try/catch blokları ve DevTools konsol hata yakalama mekanizması oluşturun.
// DOM Elemanlarını Seçme
const sensorBtn = document.querySelector('#sensor-read');
const sensorOut = document.querySelector('#sensor-value');
const ledBtn = document.querySelector('#led-toggle');
const ledState = document.querySelector('#led-state');
const ledIndicator = document.querySelector('#led');

// Sensör Simülasyonu (20 - 30 °C aralığında rastgele değer)
sensorBtn?.addEventListener('click', () => {
  const randomTemp = (20 + Math.random() * 10).toFixed(1);
  sensorOut.textContent = `${randomTemp} °C (Canlı Ölçüm)`;
});

// Sanal LED / Röle Durum Kontrolü
ledBtn?.addEventListener('click', () => {
  const isPressed = ledBtn.getAttribute('aria-pressed') === 'true';
  const nextState = !isPressed;
  ledBtn.setAttribute('aria-pressed', String(nextState));
  ledIndicator?.classList.toggle('on', nextState);
  ledState.textContent = nextState ? 'LED Aktif (Açık)' : 'LED Pasif (Kapalı)';
  console.log(`Donanım durumu güncellendi: ${nextState ? 'HIGH' : 'LOW'}`);
});

Tarayıcı simülasyonu · fiziksel sensöre bağlı değildir.

Yapay Zekâ ile Çalışma

Elektrik-elektronik ölçüm arayüzü için modern JavaScript (ES6+) kodu yaz. querySelector ve addEventListener ile buton tıklamalarını dinle. Bir butonla sanal sensör sıcaklığını rastgele simüle ederek DOM'u güncelle. Diğer butonla sanal LED rölesini açıp kapat, aria-pressed ve classList.toggle yönet. Form üzerinden gerilim ve akım alıp P=V*I güç hesabını anlık yapan fonksiyonu ekle. Antigravity AI destekli try/catch hata yönetimi ve DevTools console loglarını dahil et.

Doğrulama kontrolü

  • Tarayıcı Konsolunda (F12 -> Console) herhangi bir JavaScript Uncaught TypeError veya sözdizimi hatası olmadığını doğrulayın.
  • Sensör güncelleme ve LED butonlarının tıklandığında DOM elemanlarını ve aria-pressed değerini başarıyla değiştirdiğini test edin.
  • Sayfanın GitHub Pages üzerinde hatasız çalıştığını ve yerel dosya yollarının doğru bağlandığını teyit edin.

Kendini Test Et

1. Modern JavaScript'te let ve const anahtar kelimelerinin eski var anahtarına göre en temel üstünlüğü nedir?

var fonksiyon kapsamlı (function scope) iken; let ve const süslü parantezlerle sınırlı blok kapsamına (block scope) sahiptir, değişkenlerin kaza eseri ezilmesini önler ve güvenli kod yazımını sağlar.

2. DOM (Document Object Model) manipülasyonunda textContent ile innerHTML arasındaki güvenlik farkı nedir?

textContent yalnızca düz metin ekler ve XSS (Cross-Site Scripting) saldırılarına karşı güvenlidir; innerHTML ise HTML etiketlerini derlediği için güvenilmeyen kullanıcı girdisi verildiğinde güvenlik açığı yaratabilir.

3. Bir butonun tıklanma durumunu yönetirken aria-pressed özniteliğini güncellemenin önemi nedir?

Görsel değişimin yanında yardımcı teknolojilere (ekran okuyucular) butonun açık/kapalı mantıksal durumunu bildirerek web erişilebilirliği (accessibility) standartlarını sağlar.

4. JavaScript'te asenkron programlama (async/await ve Fetch API) neden sensör telemetrisi için vazgeçilmezdir?

Ağdan veri gelirken tarayıcının ana iş parçacığını (UI thread) kilitlemeden arka planda veriyi alır, böylece kullanıcı arayüzü donmadan sensör değerleri akıcı biçimde güncellenir.

5. Google DeepMind Antigravity ortamında JavaScript hata ayıklama süreci nasıl hızlanır?

Yapay zekâ ajanları DevTools konsol hatalarını ve asenkron Promise reddedilmelerini (unhandled rejections) otomatik analiz eder, olası mantık hatalarını kod içinde işaretleyip anında çözüm önerir.

6. JavaScript'te 'Event Bubbling' (Olay Kabarcıklanması) nedir ve addEventListener ile nasıl yönetilir?

Bir elemana tıklandığında olayın en içteki elemandan başlayarak ebeveyn düğümlere doğru yukarı yayılmasıdır; event.stopPropagation() ile durdurulabilir veya tek bir üst ebeveyne dinleyici bağlanarak (Event Delegation) bellek tasarrufu sağlanır.

7. Sensör haberleşmesinde JSON.stringify() ve JSON.parse() metotlarının rolleri nedir?

JSON.stringify() bir JavaScript nesnesini ağdan gönderilecek JSON metin dizgisine dönüştürür; JSON.parse() ise ağdan gelen JSON metnini tarayıcıda işlenebilir bir JavaScript nesnesine çevirir.

8. Canlı sensör simülasyonunda setInterval() ile setTimeout() arasındaki fark nedir?

setTimeout() belirlenen süre sonunda tek seferlik bir fonksiyon çalıştırırken; setInterval() iptal edilene (clearInterval()) kadar belirlenen periyotlarla fonksiyonu sürekli tekrarlar.

9. Sayfa kapatılıp açıldığında kullanıcının Koyu/Açık tema tercihini korumak için localStorage nasıl kullanılır?

localStorage.setItem('theme', 'dark') ile anahtar-değer ikilisi halinde tarayıcı hafızasına yazılır ve localStorage.getItem('theme') ile okunarak sayfa yenilendiğinde tercih korunur.

10. ES6 Şablon Dizgilerinin (Template Literals - ters tırnak `...`) klasik string birleştirmeye (+) göre avantajları nelerdir?

Çok satırlı metinleri doğrudan yazabilme ve ${degisken} sözdizimiyle metin içine kolayca dinamik değer ve matematiksel işlem gömebilme esnekliği sunar.
